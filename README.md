# Zentra

Marketing site and WhatsApp ops CRM for [Zentra](https://zentra-steel.vercel.app) — a technology studio that builds websites, automation, and software for businesses.

**Live:** [zentra-steel.vercel.app](https://zentra-steel.vercel.app)

## What it includes

- Public site: packages, custom solution builder, enquiry form
- WhatsApp assistant (Ada) that answers from published business knowledge
- Internal ops: leads, chats, enquiries, and follow-up

## Tech stack

| Layer | Technology |
|-------|------------|
| App | Next.js, React, TypeScript |
| UI | Tailwind CSS |
| Data | Prisma, PostgreSQL |
| Messaging | WhatsApp Cloud API |
